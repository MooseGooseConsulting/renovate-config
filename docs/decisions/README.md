# Decision Records

Use this directory for durable architecture or policy decisions that change how
the shared Renovate preset is governed.

Create a new ADR when a review chooses to promote an inspiration pattern into
shared policy, add a named preset, change dashboard posture, adopt custom
managers or datasources, change automerge posture, or materially alter the
agent-review workflow.

## Records

- [ADR 0001](0001-fleet-release-age-soak.md): fleet-wide 4-day release-age soak.
- [ADR 0002](0002-dashboard-visibility-and-uncapped-security-fixes.md): Dependency Dashboard on; security fixes uncapped.
- [ADR 0003](0003-one-non-major-pr-and-five-slots.md): one non-major PR per repository; five PR slots.
